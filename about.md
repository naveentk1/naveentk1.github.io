Hi, I'm naveentk1.

I write about low-level GPU work, porting programs to new platforms, and getting SteamOS running on hardware it was never meant to run on — like the PS5.

Topics I cover:

- **GPU driver optimisation** — digging into Mesa, RADV, and kernel-level GPU drivers
- **Program porting** — getting software to run on architectures and OSes it wasn't built for
- **SteamOS on PS5** — documenting the journey of running Valve's gaming OS on PlayStation 5 hardware

If you're into hacking hardware, kernel drivers, or just curious about what runs under the hood of your GPU, you're in the right place.
